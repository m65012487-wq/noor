# Ассеты Tasbih

- `environment/`: готовый сгенерированный пейзаж без центрального дерева, отдельные SVG земли, дорожки и переднего плана.
- `gate/`: пять прозрачных векторных слоёв ворот, створки независимы.
- `atmosphere/`: четыре тихих опциональных SVG-слоя, по умолчанию выключены.
- `tree/`: инструкция регистрации; рабочие пять SVG уже находятся в `assets/garden/plants/olive/` и намеренно не дублируются.
- `../../docs/design/tasbih-candidates/`: пять новых растровых вариантов дерева, отклонённых для подключения из-за ореола/масштаба. Не входят в приложение.

Размеры, alpha, anchors, z-order, промпты и правила замены: `docs/TasbihAssetManifest.md`.
