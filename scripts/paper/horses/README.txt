Двенадцать кадров галопа, вырезанных из раскадровки, которую прислал
владелец приложения. Силуэты чёрные, прозрачность взята из светлоты
исходника, поэтому красить их можно в любой тон — см. tinted() в ../herd.js.

Кадры идут по циклу галопа: h01–h06 первый ряд раскадровки, h07–h12 второй.
Для ряда берутся заведомо разные кадры — одинаковые читаются одной фигурой,
размноженной под копирку.
