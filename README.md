# Noor

Мусульманское приложение для iPhone: время намаза, кибла, Коран, обучение арабскому чтению и ежедневное чтение.

Expo SDK 54 · React Native 0.81 · React 19 · iOS 18+, Liquid Glass на iOS 26.
Около 7 800 строк JavaScript и Swift. Данные хранятся на устройстве, аккаунта нет.

---

## Разделы

Навигация — четыре вкладки внизу экрана, панель в стиле Liquid Glass.

| Вкладка | Экран | Что внутри |
|---|---|---|
| **Намаз** | `PrayerTimesScreen` | Кольцо обратного отсчёта, фаза луны, две даты, расписание на день |
| **Кибла** | `QiblaScreen` | Компас с направлением на Каабу |
| **Коран** | `QuranScreen` → `SurahReaderScreen` | Суры, перевод, пословный разбор, чтецы |
| **Чтение** | `ReadingScreen` | Ежедневная цель, серия, аят дня |

Обучение арабскому чтению (`LearnScreen`, `CoursePathScreen`, `LessonPlayerScreen`) — курс из 14 юнитов: от первых букв через огласовки и слоги к словам.

## Время намаза

### Главный экран

- **Кольцо** отмеряет промежуток между предыдущим и следующим намазом.
- **Луна** внутри кольца освещена ровно на ту долю, что сегодня на небе. При открытии экрана набирается за 1,4 секунды.
- **Две даты** — григорианская и по хиджре. Нажатие открывает календарь.
- **Расписание** свёрнуто в спойлер и в свёрнутом виде показывает намаз через один: ближайший уже стоит в кольце.
- Строки расписания лежат прямо на обоях, без плиток; читаемость держит тень под текстом.

### Источники расчёта

| Источник | Как считается |
|---|---|
| **Кавказ (ДУМ КБР)** | На устройстве, `dumCalc.js`, по методу, восстановленному из официальных графиков |
| Лига исламского мира, Турция, Египет, Умм аль-Кура, Карачи, ISNA | Aladhan API; без сети — локально через `adhan` |
| Офлайн | На устройстве, `adhan` |

#### Метод ДУМ КБР

Ни одна библиотека его не воспроизводит: у ДУМ **угол ограничен по времени**, а библиотеки знают только «угол плюс постоянный сдвиг».

| Время | Правило |
|---|---|
| Фаджр | Угол 15°, но не позже чем за 90 минут до восхода |
| Восход | Астрономический |
| Зухр | Солнечный полдень + 10 мин |
| Аср | Шафиитский счёт (коэффициент тени 0,99) + 10 мин |
| Магриб | Закат + 2 мин |
| Иша | Угол 15,25°, зажатый между 103 и 112 минутами после заката |

Совпадение с официальным графиком на 91 дне (июнь, сентябрь, декабрь 2026):

| Время | В пределах минуты | Макс. ошибка |
|---|---|---|
| Восход, Зухр, Магриб | 91 / 91 | 1 мин |
| Фаджр | 88 / 91 | 2 мин |
| Иша | 81 / 91 | 3 мин |
| Аср | 62 / 91 | 3 мин |

Точнее формулой не выйдет: официальная таблица сглажена вручную. До минуты совпадёт только сама таблица, встроенная в приложение (весь год ≈ 15 КБ JSON).

> Aladhan с методом 14 «ДУМ РФ» для Кабардино-Балкарии неверен: на 7 сентября 2026 даёт Ишу 19:52 против официальных 20:16.

Официальные графики лежат картинками: `https://dinri-duneiri.ru/azan/2026009.jpg` — год и месяц с ведущим нулём.

### Календарь

Лист на месяц: числа григорианского календаря крупно, по хиджре мелко под ними, неделя с понедельника. Внизу — времена намаза на выбранный день и освещённость луны.

Хиджра считается **табличным (кувейтским) алгоритмом**, а не через `Intl`: в Hermes набор календарей неполон и молча отдаёт григорианскую дату. Месяц по хиджре начинают по наблюдению молодого месяца, поэтому таблица расходится на день-другой. Поправка — в настройках, по умолчанию −1 (сверено с ДУМ КБР на 7 сентября 2026).

### Уведомления

- В момент каждого намаза и восхода, плюс напоминание заранее — отдельным уведомлением.
- Звук напоминания и звук наступления времени выбираются **раздельно** из общего списка: системный, колокольчик, колокол, тихий. Каждый можно прослушать.
- Уровень **Time Sensitive** — пробивает режим сна и «Фокус».
- Расписание на 4 дня вперёд. iOS держит не больше 64 отложенных уведомлений, 12 мест оставлено будильнику.

**Азан в уведомлении звучать не может.** iOS пускает туда только несжатый файл из бандла не длиннее 30 секунд, а азаны — mp3 по сетевым ссылкам длиной в минуты. Азан проигрывается в приложении.

### Умный будильник на Фаджр

- Первые 6 звонков раз в минуту, дальше с выбранным интервалом, до восхода. Не больше 12.
- Собственный звук на 29 секунд (`alarm.wav`) — предел для звука уведомления.
- Открытие приложения или «Я проснулся» останавливает цепочку.

Боковой переключатель в бесшумном режиме глушит любой звук уведомления. Обойти это может только Critical Alerts — разрешение Apple, выдаётся по заявке при платном аккаунте разработчика.

## Кибла

Компас на `expo-location`: истинный курс, при недоступности — магнитный. Вращается только циферблат; стеклянный диск неподвижен, чтобы блик не крутился вместе со шкалой.

Буквы сторон света повёрнуты **по радиусу**, как на картушке компаса: при повороте телефона сторона, к которой повернулся, оказывается вверху ровно стоящей буквой.

## Коран

- Текст, перевод и пословный разбор **встроены** (`assets/quran`, 6,8 МБ) и работают без сети.
- Сеть нужна для аудио чтецов (`api.alquran.cloud`) и пословного разбора при первом открытии суры (`api.quran.com`).
- Закладки, место последнего чтения и масштаб шрифта хранятся на устройстве.
- Настройки чтения — отдельный лист: чтец, перевод, показ арабского, транслитерации и перевода, пословный режим, арабский шрифт.

## Оформление

Три независимые оси.

### Узор

| Род | Варианты | Как рисуется |
|---|---|---|
| Без узора | — | Градиент схемы |
| Плитки | Цветок, Гирих, Купола, Фонари | Бесшовная плитка |
| Сцены | Город, Пустыня, Полумесяц | Три плана с **параллаксом** при наклоне телефона |

Все картинки белые на прозрачном и красятся тоном схемы, поэтому одна картинка работает со всеми схемами.

Параллакс: дальний план сдвигается на 7 точек, ближний на 30. Опорный угол медленно подтягивается к текущему — сцена сама возвращается в центр, когда телефон замирает. Системное «Уменьшение движения» выключает эффект.

### Цветовая схема

10 вариантов: 5 глубоких (Тушь, Песок, Мох, Слива, Пепел) и 5 светлых (Жемчуг, Лён, Шалфей, Сирень, Роза). Светлоту ограничивает контраст приглушённого текста.

### Шрифт интерфейса

6 наборов, у каждого кириллица проверена по таблице `cmap` файла.

| Набор | Семейство | Откуда |
|---|---|---|
| Системный | SF Pro | iOS |
| Округлый | SF Pro Rounded | iOS |
| Гротеск | PT Sans | Встроен в `assets/fonts` |
| Широкий | Verdana | iOS |
| С засечками | Georgia | iOS |
| Книжный | PT Serif | Встроен в `assets/fonts` |

Шрифт без кириллицы ничего не ломает: iOS подменяет буквы системным шрифтом посимвольно, и настройка выглядит нерабочей. Поэтому Gill Sans, Avenir Next, Optima, Futura и Iowan Old Style исключены.

### Арабский шрифт

6 встроенных в iOS: Системный, Geeza Pro, Al Nile, Damascus, Mishafi, Baghdad.

## Виджет

WidgetKit через `@bacons/apple-targets`, код в `targets/widget`.

- **Домашний экран** — все времена на день, включая самый маленький квадратный виджет.
- **Экран блокировки** — три ближайших времени.

Виджет не считает времена сам: приложение публикует готовый срез дня в общую App Group (`widgetBridge.js`). Иначе на Swift появился бы второй источник правды, который однажды разошёлся бы с приложением.

### Дизайн-система

`src/constants/theme.js`. Экраны не изобретают значения: кегли, отступы, радиусы и цвета берутся отсюда. До её появления в коде было 22 разных кегля и 9 цветов мимо палитры.

| Токен | Значения |
|---|---|
| `TYPE` | hero 46 · display 36 · title 28 · heading 22 · subhead 18 · body 16 · callout 14 · caption 12 · overline · mono |
| `SPACING` | 2 · 4 · 8 · 16 · 24 · 32 · 48 |
| `RADIUS` | 10 · 20 · 28 · pill |
| `ARABIC` | 24/46 · 30/56 · 34/64 · 44/80 — кегль / межстрочный |

### Шрифт по всему приложению

В React 19 `Text.defaultProps` не работает, поэтому все тексты идут через `AppText`. Он подмешивает выбранное семейство **под** переданный стиль. `fontFamily: 'System'` служит маркером арабского текста и заменяется выбранным арабским шрифтом.

### Генераторы ассетов

Картинки и звуки нарисованы и синтезированы кодом, внешних ассетов нет.

| Скрипт | Что делает |
|---|---|
| `scripts/patterns/build.js` | Бесшовные плитки: рисует поле 3×3 и вырезает центр — края гарантированно стыкуются |
| `scripts/scenes/build.js` | Сцены по три плана для параллакса |
| `scripts/icon/build.js` | Иконка, adaptive-иконка, заставка |
| `scripts/sounds/build.js` | Звуки уведомлений и будильника |

Генераторам нужен `sharp`. Он ставится без сохранения и между запусками пропадает:

```bash
npm install sharp --no-save
```

## Сборка

### Проверка на Windows

Mac нет, поэтому iOS-проект локально не компилируется, но JS проверяется полностью:

```bash
npx eslint src/ App.js
```

```bash
npx expo export --platform ios
```

Второе прогоняет весь Metro: выход 0 означает, что бандл собирается.

### .ipa

GitHub Actions, `.github/workflows/unsigned-ipa.yml`, раннер `macos-15`. Нативного проекта в репозитории нет — его разворачивает `expo prebuild` на раннере.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `include_widget` | `true` | Собирать с виджетом |
| `bundle_id` | `app.noor.mobile` | Bundle ID |

```bash
gh workflow run unsigned-ipa.yml
```

Сборка неподписанная, подпись — через eSign на самом iPhone, сертификат в CI не попадает.

**Bundle ID обязан отличаться от других приложений на устройстве**: одинаковый iOS считает обновлением и затирает соседнее приложение вместе с данными.

### Конфигурация `app.json`

- `expo-notifications` — звуки уведомлений: `chime`, `bell`, `soft`, `alarm`.
- `expo-font` — PT Sans и PT Serif, регистрируются на сборке.
- `expo-splash-screen` — заставка.
- `ios.entitlements` — App Group для виджета и `time-sensitive` для уведомлений.

## Известные ограничения

| Что | Почему |
|---|---|
| Азан не звучит в уведомлении | Нужен несжатый файл ≤ 30 с из бандла; азаны — mp3 по сети |
| Будильник молчит в бесшумном режиме | Обойти может только Critical Alerts от Apple |
| ДУМ КБР — до ±3 минут | Официальная таблица сглажена вручную; точно — только встроенной таблицей |
| Хиджра может разойтись на день | Месяц начинают по наблюдению; есть поправка в настройках |
| Метод ДУМ подогнан под Нальчик | Дагестан, Чечня и другие ведут свои графики — проверять отдельно |
| `time-sensitive` может не пережить переподпись | Тогда уведомления не пробьют «Фокус»; остальное работает |
